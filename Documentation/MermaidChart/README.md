# Notes on using MermaidChart

Diagram are rendered automatically from code in various places, including in the DIRECT GitHub.

The files in this directory use Mermaid to create the images found in the 'Images' directory.

For more information:

* [https://mermaid.js.org/](https://mermaid.js.org/)
* [https://github.com/mermaid-js/mermaid](https://github.com/mermaid-js/mermaid)
* [https://www.mermaidchart.com](https://www.mermaidchart.com).
